From your AI agent

  "type": "http", "url": "/mcp" } } }
Search/api/search?q=Anything on chain, best first

Status/api/statsWhat is indexed, up to which block

Everything returned was written on chain by anyone, so show it as text. About 8 searches a second per user; above that you get 429, wait a moment.

Full reference

Search

ParameterMeaning
qWords, a package path, an address, a token symbol or a transaction hash prefix (up to 200 characters)
n, offsetHow many results (1 to 50, 20 by default) and how many to skip; more says whether more follow, up to 100 deep
netmain (default) or test
kindOnly realm, pkg, code, user, token or tx

Each result has url, kind, title, snippet (matches between U+0002 and U+0003), and what it was ranked by: users this month, imports and links (other owners, each counted once). gnot is GNOT sent in this month, as a decimal string; it is shown, not ranked.

Read

/api/page?u= takes a result's url and returns its markdown in md: a realm page, live when possible (gno.land/r/..., with :path for a sub-page), a package (gno.land/p/...), a realm's source (...$source), a token (token:...), an account (user:g1..., with its live balance) or a transaction (tx:HASH).

Who uses it

/api/importers?u=gno.land/p/...: the packages and realms that import it, most used first.

Agents

POST /mcp speaks MCP over HTTP, one request and one answer, with the tools search, find_package, read_page, who_imports and stats. To run the tools on your own machine instead, see the mcp folder of the source.
