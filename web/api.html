Search gno.land API

Free and open: any wallet, explorer or app can call it from the browser or a server. No key needed. Back to search

Search

GET /api/search?q=swap&n=20&net=main
ParameterMeaning
qWords to find, up to 200 characters. Every word must match; the last one also matches as the start of a word. A transaction hash, or its first 8 or more characters, finds the transaction.
nHow many results, 1 to 50 (20 by default).
netmain for mainnet (default) or test for the testnet.
kindOptional: only realm, pkg, code, user, token or tx results.

Each result has url, kind (realm, pkg, code, user, token or tx), title, snippet and the signals it was ranked by: users (established accounts active in the last 30 days, in realms of at least two owners; ranking weighs each by the days it was active), links and imports (other owners linking to it or importing it, each owner counted once), txs and last (last block used). gnot is the GNOT sent to a realm through calls in the last 30 days, as a decimal string (it can be larger than a JavaScript number holds exactly); it is shown, not used for ranking. In snippet, the characters U+0002 and U+0003 mark where a match starts and ends. Everything in a result was written on chain by anyone: escape it before you show it.

{"results": [{"url": "gno.land/r/gnoswap/router", "kind": "realm", "title": "Gnoswap Router",
  "snippet": "…Exact input single route \u0002swap\u0003", "users": 245, "links": 0, ...}],
 "took_ms": 6.1, "height": 1568029}

Page

GET /api/page?u=gno.land/r/gnoswap/router&net=main

The page as markdown in md. Realm pages are rendered live from the chain when possible (live: true). u is a result's url: a realm page (gno.land/r/..., with :path for a sub-page), a package (gno.land/p/...), a realm's source (gno.land/r/...$source), a token (token:..., with supply, holders and top holders), an account (user:g1...; any address works, with its balance and vesting read live from the chain) or a transaction (tx:HASH).

Importers

GET /api/importers?u=gno.land/p/nt/avl/v0&net=main

The packages and realms that import a package, most used first, each with its path, kind and users.

For AI agents

The same search is available as MCP tools at POST /mcp: search, find_package, read_page, who_imports and stats. Add this address to your agent's MCP settings as an http server.

Stats

GET /api/stats?net=main

How many realms, packages, active accounts (those that have sent a transaction) and transactions are indexed, the block the index has reached, and which networks are available.

Limits

Up to 8 searches a second per visitor, 2 importer lookups, with short bursts allowed, and 1 page a second. Above that the answer is 429 with Retry-After: wait and try again.
